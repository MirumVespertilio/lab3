# Лабораторная работа №3 - Системы контроля версий (VCS)

## Описание проекта
Анализ статистических данных с использованием методов экстраполяции по скользящей средней.

## Авторы
- **MirumVespertilio** - Вариант 18: Анализ потребительских расходов
- **RomanoffD** - Вариант 7: Анализ браков и разводов

## Структура веток
- `main` - основная ветка
- `dev` - ветка разработки
- `feature/expenses` - реализация варианта 18 (потребительские расходы)
- `feature/marriage` - реализация варианта 7 (браки и разводы)

## Технологии
- Python 3.x
- CustomTkinter (GUI)
- Matplotlib (графики)

## Функциональность
- Загрузка данных из JSON файлов
- Отображение данных в табличном формате
- Построение интерактивных графиков
- Прогнозирование методом скользящей средней
- Экспорт графиков в PNG/PDF

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Вариант 18: Потребительские расходы
- Данные о среднедушевых потребительских расходах населения России (2010-2024)
- Расчёт максимального и минимального процента изменения
- Прогнозирование будущих расходов
