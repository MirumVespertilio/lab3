# Лабораторная работа №3 - Системы контроля версий (VCS)

## Описание проекта
Анализ статистических данных с использованием методов экстраполяции по скользящей средней.

## Авторы
- **Аккаунт 1** - Вариант 18: Анализ потребительских расходов
- **Аккаунт 2** - Вариант 7: Анализ браков и разводов

## Структура веток
- `main` - основная ветка
- `dev` - ветка разработки
- `feature/expenses` - реализация варианта 18
- `feature/marriage` - реализация варианта 7

## Технологии
- Python 3.x
- CustomTkinter (GUI)
- Matplotlib (графики)

## Функциональность
- Загрузка данных из JSON файлов
- Отображение данных в табличном формате
- Построение интерактивных графиков
- Прогнозирование методом скользящей средней
- Экспорт графиков в PNG/PDF

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Вариант 7: Браки и разводы
- Данные о браках и разводах в России (2010-2024)

- Прогнозирование тенденций
